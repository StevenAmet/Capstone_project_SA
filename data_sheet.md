# Datasheet – Black-Box Optimisation Query Data

## Motivation

The dataset was created as part of a black-box optimisation (BBO) capstone project. The purpose of the dataset is to record the relationship between input parameter vectors and the resulting performance scores from an unknown function.

The goal is to analyse how different inputs affect outputs and to iteratively improve performance over time without knowledge of the underlying function.

The dataset was generated by the student through repeated querying of the system.

---

## Composition

The dataset consists of:

- Input vectors (parameter values submitted each week)
- Corresponding output scores returned by the black-box function

Each instance represents a single query.

- Number of instances: ~12 (one per iteration/week)
- Features: numerical input parameters
- Target: scalar performance score

There is no sensitive or confidential data in this dataset.

---

## Collection process

Data was collected iteratively over multiple weeks by submitting queries to the black-box system.

- Sampling strategy: adaptive (based on previous results)
- Timeframe: course duration (12 weeks)
- Source: system-provided black-box function

---

## Preprocessing/cleaning/labelling

Minimal preprocessing was required:

- Inputs were recorded as submitted
- Outputs were recorded directly from the system
- Data was structured into a consistent format for analysis

No external cleaning or transformation was applied.

---

## Uses

This dataset can be used for:

- Analysing optimisation strategies
- Studying exploration vs exploitation behaviour
- Understanding convergence in iterative search processes

Limitations:

- Small dataset size
- Results depend on unknown function behaviour
- Limited generalisability

The dataset should not be used for:

- Training predictive machine learning models
- General-purpose statistical inference

---

## Distribution

The dataset is not publicly distributed and is specific to the capstone project.
